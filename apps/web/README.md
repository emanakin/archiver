# Dashboard foundation

This is a Next.js starter and API client. Feed ../../docs/02-FIGMA-MAKE-BRIEF.md to Figma Make, then integrate generated components following ../../docs/03-FRONTEND.md.

`npm ci`, `npm run typecheck`, `npm run build`. The full integration runs through Compose/Caddy; standalone next dev has no /api proxy configured. The starter screen lists accounts and controls simulation pause/resume. Other dashboard screens are specified, not implemented.
